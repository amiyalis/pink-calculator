# 🌸 Pink Calculator

A beautiful, aesthetic, and fully functional calculator built with web technologies, featuring a clean pastel-pink design and glassmorphism vibes.

## 🛠️ Tech Stack
- **HTML5** & **CSS3** (Custom Properties, Flexbox, Grid)
- **JavaScript** (Calculator logic and interactivity)
- **FontAwesome** (Icons)

## ✨ Features
- 🧮 Smooth and intuitive basic mathematical operations
- 🎨 Aesthetic pastel pink theme matching modern UI trends
- 📱 Fully responsive layout for seamless use across devices
